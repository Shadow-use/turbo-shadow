# 🏎️ TURBO SHADOW | AI Auto Concept Factory

Повністю автономний конвеєр з генерації та публікації унікального автомобільного контенту, керований штучним інтелектом.

## 📖 Про проєкт

**Turbo Shadow** — це serverless-архітектура, розгорнута на базі GitHub Actions. Проєкт щодня, без втручання людини, проходить повний цикл створення контенту: від генерації унікального концепту автомобіля до верстки фінального макета ("фантика") та публікації в Telegram-канал. 

Система має власну пам'ять (захист від дублікатів) та жорсткий 7-денний розклад, де кожен день тижня має унікальний режисерський стиль, атмосферу та правила для генерації.

## ⚙️ Як це працює (Pipeline)

1. **Brainstorming (LLM):** Звернення до `gpt-4o-mini` (через GitHub Models API) для вибору авто, генерації технічних характеристик та складання детального кінематографічного промпту.
2. **Visualization (Text-to-Image):** Звернення до Pollinations.ai API для генерації зображення (1000x700, 8k, photorealistic). Використовується динамічний `seed` для уникнення кешування.
3. **Design & Layout (Pillow):** Python-скрипт накладає згенероване авто на тематичний фон дня, додає фірмовий логотип проєкту, рендерить таблицю ТТХ та унікальний серійний номер.
4. **Broadcasting (Telegram API):** Готовий макет автоматично відправляється в Telegram-канал із згенерованим HTML-описом.
5. **State Management:** Запис характеристик авто в `used_cars.json` для збереження історії та автоматичної інкрементації серійних номерів (ID). Збереження відбувається лише після успішної публікації.

## 📅 7-Денний Контент-План (Матриця стилів)

Кожен день тижня підтягує власний конфігураційний `.json` файл з інструкціями для ШІ:

* 🟢 **Понеділок:** `Легенди 90-х` — плівкова ностальгія та JDM/європейська класика.
* 🟣 **Вівторок:** `Midnight Crew` — неоновий стріт-рейсинг, динаміка та нічний андеграунд.
* 🟤 **Середа:** `Garage Finds` — запах старої олії, хром, вінтаж та кінематографічне світло.
* 🔵 **Четвер:** `Hyper Speed` — шалена швидкість 400+, аеродинаміка та максимальний motion blur.
* 🟠 **П'ятниця:** `Off-Road Beasts` — повний привід, бруд, екстремальні локації та агресивна погода.
* ⚫ **Субота:** `Shadow Concepts` — чиста фантастика, кіберпанк та неіснуючі технології 2077+ року.
* 🟡 **Неділя:** `UA Custom Concepts` — рідне, тепле, могутнє. Елегантна інтеграція українського стилю у дизайн майбутнього.

## 🏗️ Архітектура та Стандарти Коду

Проєкт побудований за принципом чіткого розділення відповідальності (Separation of Concerns). Кожен модуль містить строгу мітку `// Responsibility:` на початку файлу.

* `main.py` — Головний контролер. Збирає дані, запускає процеси та обробляє відправку в Telegram.
* `brain.py` — ШІ-логіка (комунікація з GitHub Models та Pollinations.ai).
* `painter.py` — Графічний рушій (робота з PIL/Pillow для збірки макета).
* `storage.py` — Робота з файловою системою, визначення дня тижня та управління історією (`used_cars.json`).

## 🚀 Технології та Інструменти

* **Мова:** Python 3.x
* **Автоматизація CI/CD:** GitHub Actions (Cron Jobs)
* **Графіка:** Pillow (PIL)
* **ШІ Текст:** GitHub Models (`gpt-4o-mini`)
* **ШІ Зображення:** Pollinations.ai API
* **Інтеграція:** Telegram Bot API
