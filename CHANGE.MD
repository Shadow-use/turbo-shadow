​Ми розширили можливості архітектури для гнучкішого керування та підвищення візуальної якості контенту:
​📈 High-Res Visuals: Збільшено роздільну здатність генерації до 1500x1050. Тепер деталізація концептів та чіткість шрифтів на макетах відповідають стандартам сучасних дисплеїв.
​🎉 Holiday Engine: Впроваджено підтримку holidays.json. Система автоматично розпізнає святкові дати та адаптує промпти й дизайн під тематичні івенти, перекриваючи стандартний розклад.
​🛠️ Manual Test Mode: Додано можливість ручного запуску пайплайну через GitHub Actions (workflow_dispatch). Тепер можна тестувати нові ідеї в окремому режимі без публікації в основний канал.
​🧠 Refactored Brain: Оптимізовано логіку brain.py для безпечної обробки святкових конфігурацій та покращеної стабільності взаємодії з LLM.
